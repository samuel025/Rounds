- 2026-11-06 extra hand-derived vectors (expected values derived on paper BEFORE running the engine; all four then matched the engine and the Python reference):
  - Common setup: Ada 9,000,000 common, pool 1,000,000 (N = 10,000,000), V = $20M, new money $5M from Fund. Post-money price P = (V - t*V')/X, and with t = 0 the pool is "no top-up" so P = V/(X + pool).
  - GV-5A (cap wins): $1M SAFE, $10M cap, 20% discount. Cap_pre = 10,000,000/0.9 = 11,111,111.1, so the cap price is $0.90 and S = floor(0.1 * Cap_pre) = 1,111,111. P = 20,000,000/(10,000,000 + 1,111,111) = 1.80000018 -> $1.8000. Discount price = 0.8 * 1.80 = $1.44 > $0.90, so cap wins. Fund = floor(5,000,000/1.80) = 2,777,777. FD = 13,888,888.
  - GV-5B (discount wins): same but a $100M cap (cap price about $9.90). With the discount: S = 1,000,000/(0.8 P) and P(10,000,000 + S) = 20,000,000, so P * 10,000,000 + 1,250,000 = 20,000,000 and P = $1.875. S = 1,000,000/1.50 = 666,666. Fund = floor(5,000,000/1.875) = 2,666,666. FD = 13,333,332 (x $1.875 = $24,999,997.50, i.e. post-money $25M within rounding).
  - GV-6 (no top-up): no SAFEs, 5% target. P = 20,000,000/(9,000,000 + 1,000,000) = $2.00; the 5% target needs 0.05 * 25M/2 = 625,000 < 1,000,000, so no top-up. Fund = 2,500,000; FD = 12,500,000.
  - GV-7 (down round): $1M SAFE with a $20M cap, V = $10M, new money $2M, no discount. At the cap it would get 526,315 shares and a $1.90 cap price, but the round price is far lower, so it converts at the round price: P(10,000,000) + 1,000,000 = 10,000,000 gives P = $0.90, S = floor(1,000,000/0.90) = 1,111,111 (regime discount, price $0.9000). Fund = floor(2,000,000/0.90) = 2,222,222. FD = 13,333,333.
